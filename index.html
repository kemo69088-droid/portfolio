§1

Profile

I am an Artificial Intelligence undergraduate who spends most of his time on the unglamorous half of data work: getting a file into a state where it can actually answer a question.

My training runs on two tracks at once. At the Faculty of Artificial Intelligence, Kafr El-Sheikh University, I study the statistics and machine learning that sit underneath the tools. In the Digital Egypt Pioneers Initiative — Data Science track, Round 5 — I practise the applied side of it: cleaning, analysing, modelling and reporting on real datasets.

What I offer is not a long list of technologies. It is a short one I can defend in a room: Excel and SQL to get the data out, Python to clean and analyse it, Power BI to put it in front of the person who has to make the call. Where a question needs a model rather than a report, I build one — regression for numbers, convolutional networks for images.

I work in Arabic natively and in English at an intermediate level, which is enough to read documentation, write a report, and sit an interview.

Selected work

Three figures
Fig. 01

Cat & dog image classifier

A convolutional neural network that reads a photograph and labels it as a cat or a dog. Built end to end: preparing and augmenting the image set, designing the network, training it against a held-out validation split, then reading the loss and accuracy curves to see where it was learning and where it was memorising.

The value of this one was not the labels. It was learning to tell a model that is genuinely generalising from one that has simply learned the training set by heart.

Role
Built end to end, solo
Stack
Python · TensorFlow · NumPy · Matplotlib
Focus
Preprocessing, augmentation, CNN architecture, overfitting control
Fig. 02

House price prediction

A regression model that estimates the price of a property from its features. The interesting part sat before the model: deciding which columns carried real signal, handling the missing ones honestly, and splitting the data so the score I reported was earned on rows the model had never seen.

I evaluate it the way a client would want it evaluated — by plotting predicted against actual and looking at where, and for which kind of property, it is wrong.

Role
Built end to end, solo
Stack
Python · pandas · scikit-learn · Matplotlib
Focus
Feature preparation, train/test split, regression, error inspection
Fig. 03

Olist Brazilian e-commerce analysis

In progress — DEPI R5

A Power BI report built on the public Olist dataset: seven related tables covering orders, order items, payments, reviews, customers, products and sellers. The first half of the job is modelling — joining those tables into something that answers questions without double-counting a single order.

The second half is deciding what a store owner would actually want on the page: where the orders come from, how people pay, how long delivery takes, and what the review scores say about the difference.

Role
Data model and report, solo
Stack
Power BI · Microsoft Excel
Focus
Seven-table model, order flow, payment behaviour, review scores
