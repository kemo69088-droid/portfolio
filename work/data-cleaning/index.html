Fig. 05

Reusable on any CSV or Excel file

Python · pandas
# the toolkit in four lines
from data_cleaner import DataCleaner

dc = DataCleaner("titanic.csv", missing_threshold=0.60)
dc.profile()      # types, missing %, uniques per column
dc.clean()        # the six steps above, logged
dc.save("titanic_cleaned.csv"); dc.report("cleaning_report.html")

One class, open source on GitHub. The same call produced every number on this page.

Method & definitions

  • Demo file: the public Titanic passenger list (seaborn copy). Figures come from running data_cleaner.py on it, unedited.
  • Missing threshold 60%: columns emptier than that are dropped, the rest are filled (median for numbers, most common value for text).
  • Outliers use the 1.5 × IQR rule per numeric column and are flagged, never deleted automatically.
